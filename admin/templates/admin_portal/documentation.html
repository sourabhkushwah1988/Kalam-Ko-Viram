Publishing poetry

Create an entry from Poetry & Shayari → New poetry. Choose its author, category, poetry type and language, then enter the content.

Select Published to make it available through the website's existing published-poetry queries. Published entries receive a publish date automatically. Select Draft to keep an entry private.

Featured collections

Featured, trending and daily flags control which published entries are used by their corresponding website sections.

Access

Portal access is controlled by Django model permissions. Grant only the poetry, author, category or user permissions each customer account needs. Users shown under App Users are read-only.
